# Brewery Conflict Corpus

Created: 2026-06-26

This corpus documents environmental conflicts, injustice concerns, water-use disputes, wastewater/effluent issues, land-use disputes, gentrification/displacement scholarship, and legal/policy conflicts involving breweries, craft beer, and brewery supply chains.

## Methods

The build used global, English-language searches from 2000 to present. Sources were screened against the relevance criteria in the brewery-conflict-corpus-builder skill. Included records needed to concern brewing/beer supply chains and also document a conflict, affected group, environmental mechanism, public policy issue, legal record, or scholarly analysis.

## Access limitations and copyright

Only legally accessible open PDFs were eligible for download. In this environment, several open PDF retrieval attempts returned access/tunnel errors, so those items are represented as Markdown metadata/evidence records with full-text follow-up notes. News pages and uncertain-access sources are also represented as Markdown metadata/evidence records rather than full article captures. Restricted or uncertain scholarly sources are represented in `sources/metadata_only/`; no paywalled full text was downloaded.

## File naming

Files use `SOURCECATEGORY_YEAR_COUNTRY_SHORTTITLE_ID` names. The main evidence table is `tables/conflict_evidence_table.csv`; every row has a matching file path in `sources/`.

## Multilingual extension

The corpus was extended with Spanish and Portuguese records. For non-English sources, the original title and a short original-language evidence excerpt are retained alongside an English equivalent in `tables/conflict_evidence_table.csv`, `tables/multilingual_translation_table.csv`, and each source Markdown record. Existing English records were preserved.

## Expanded language coverage

The corpus now includes English, Spanish, Portuguese, French, Dutch, German, and Italian records. New European-language additions include microbrewery water/effluent guidance, Dutch brewery-pub nuisance and legal-permit records, German drought/water-reuse context, and Italian effluent and nightlife-noise context. Some additions are contextual rather than conflict-specific and are marked with lower confidence where appropriate.
