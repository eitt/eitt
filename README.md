I am a professor and researcher in Colombia with a PhD in Engineering. I use optimization, statistics and machine learning to study decisions in agriculture, organizations and social systems. I also develop teaching resources that connect mathematical models with data and interactive applications.

## Research software

| Project | What I investigate | Main methods |
| :--- | :--- | :--- |
| [Turbofan remaining useful life](https://github.com/eitt/measurement-and-control) | Neural prediction and pruning experiments using NASA C-MAPSS data. | PyTorch · particle swarm optimization · mixed-integer programming |
| [Agricultural production planning](https://github.com/eitt/agricultural_nsgaII) | Production decisions with competing objectives and frozen benchmark instances. | SCIP · NSGA-II · surrogate models |
| [EU-27 agricultural sustainability](https://github.com/eitt/farm_models) | Composite indicators and differences between agricultural systems. | Entropy weighting · hierarchical clustering |
| [Empathy measurement](https://github.com/eitt/2026-MAP8_IRI_Empat-a) | Psychometric and configurational analysis of IRI empathy data. | Structural equation models · fsQCA · clustering |

I document each project's data requirements, execution steps and scope in its own repository.
